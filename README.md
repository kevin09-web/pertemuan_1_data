# Tugas Pertemuan 1 - Akuisisi dan Manajemen Data

## Deskripsi
Repository ini dibuat untuk memenuhi tugas mata kuliah Akuisisi dan Manajemen Data pada pertemuan pertama. Materi yang dipelajari meliputi Data Science Lifecycle, penggunaan tools dalam pengolahan data, dan pentingnya reproducibility dalam akuisisi data.

## Tujuan
- Memahami tahapan Data Science Lifecycle.
- Mengetahui tools yang digunakan dalam pengolahan data.
- Mengidentifikasi risiko pada setiap tahapan pengolahan data.
- Memahami pentingnya reproducibility dalam akuisisi data.
- Mempelajari penggunaan Google Colab dan GitHub.

## Isi Tugas
1. Melengkapi tabel Data Science Lifecycle dengan minimal dua contoh tools dan satu risiko pada setiap tahap.
2. Membuat repository GitHub yang memiliki struktur folder dan README.
3. Menulis paragraf 150–200 kata mengenai pentingnya reproducibility dalam akuisisi data beserta contoh kasus.

## Struktur Repository
```text
pertemuan_1_data/
│
├── modul_1/
├── pertemuan1 (1).ipynb
└── README.md
```

## Keterangan
- **modul_1/** : Folder untuk mengelompokkan tugas pada modul pertama.
- **pertemuan1 (1).ipynb** : File Google Colab yang berisi kode Python, hasil eksekusi, dan jawaban tugas.
- **README.md** : File yang berisi informasi dan penjelasan mengenai repository.

## Tools yang Digunakan
- Python
- Google Colab
- Pandas
- GitHub
